What it does

A save editor that understands the story around the save.

▣

Saves on a timeline

Each save becomes a card with its own screenshot, in the order you played. Shift click two to compare, Ctrl click several to edit together.

◇

The choice map

Every menu in a Ren'Py game as a graph of labels, options and endings. Click a choice to light up where it goes and how you got there.

=

Thousands of variables, calmly

A virtualized grid with fuzzy search, typed editors and keyboard control. Focus mode hands it the whole window.

⇄

Compare and bulk edit

Diff two saves, or a save against any backup. Apply one change to many saves after a dry run, or reuse it as a named preset.

⌕

Find anything

Ctrl K searches games, saves, variables, labels and commands, or opens any folder you paste into it.

✦

Repair, walkthroughs, galleries

Rebuild corrupted Ren'Py saves, add an in-game walkthrough or export an HTML guide, and unlock galleries without wiping them.

Why you can trust it

Nothing is written unless it reads back identical.

A save can be hours of someone's progress. Every write in Nodex follows the same path, and any step that fails leaves your file untouched.

  1. ReadDecode the save without running the game's code.
  2. ChangeApply your edits, keeping each value's original type.
  3. Round tripRe-encode, reload, and compare the whole structure.
  4. Back upCopy the original into a timestamped vault.
  5. WriteSwap the new file in atomically, and log it for undo.
